# Sources

| What | Where from | Used by |
| --- | --- | --- |
| `baked/`, `catalog/` | generated by `scripts/gen_sunnyside_pack.py` | `examples/sunnyside*` |

The source pack (`Sunnyside_World_ASSET_PACK_V2.1.zip` from
https://danieldiggle.itch.io/sunnyside) is NOT vendored — its license does not
permit redistributing the pack's source files. Only the baked GBA sheets and
catalog derived from it are committed.

To re-bake, download the pack yourself and point the baker at it:

```
SUNNYSIDE_SRC=/path/to/sunnyside-src python3 scripts/gen_sunnyside_pack.py
```

where the directory contains `raw/` (the pack as shipped) and `gm/` (the
GameMaker `Room1.yy` + `tileset_sunnysideworld.yy` descriptors).

The baker reads the pack's `raw/` art plus the two GameMaker data descriptors
(`Room1.yy`, `tileset_sunnysideworld.yy`) for autotile learning and building
stamps.
