# PLATFORMER ROOMS

> *Demonstrates a platformer with room-based camera transitions.*

<img src="preview.gif" alt="preview" width="480">

A side-scrolling platformer with a **room-pan camera** (classic room-lock style) —
the side-scroll counterpart of `ninja-village` (top-down). Foundation for the
platformer-combat.

The level (`src/maps.tish`, generated by `scripts/gen_platformer.py`) is a 2×2
grid of 15×10-tile rooms (30×20 tiles). The camera **locks to the player's
current room** and **slides to the next room** when the player crosses a room
edge — walking off the side, or falling through a gap into the room below —
with input frozen for the ~24-frame slide. Same platformer physics as
`platformer-scroll`; only the camera call differs.

- **d-pad**: walk left/right
- **A**: jump

The camera call is `hero.roomFollow(15, 10)` (rooms are 15×10 tiles). The room
trigger works for free-moving platformer players via the engine's
`room_track_free` system (grid/top-down players trigger from `grid_step`).

Build:

```bash
npm run build      # build the ROM
npm start          # build + open in mGBA
```

Regenerate art + level: `python3 scripts/gen_platformer.py` (repo root).

Note: streamed backgrounds page in over the first few hundred frames, so a
headless screenshot needs ~300+ frames to show the filled scene.
